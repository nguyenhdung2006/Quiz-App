# Vocabulary Quiz

Vocabulary Quiz is split into a clear small monorepo:

- `frontend`: current browser app
- `backend`: Spring Boot API
- `database`: PostgreSQL SQL
- `docs`: product and setup notes

Open `frontend/index.html` for the current client app. Run the API from `backend` with:

```powershell
.\mvnw.cmd spring-boot:run
```

Read `docs/backend-postgres.md` for PostgreSQL setup and `docs/product.md` for the product flow.
